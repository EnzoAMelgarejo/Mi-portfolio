# Mi Portfolio

Este es mi portfolio personal desarrollado con **React**. Aquí podrás conocer más sobre mí, mis proyectos y habilidades. Es una manera sencilla y moderna de mostrar mi trabajo y conocimientos como desarrollador fullstack junior.

## Características

- **Single Page Application (SPA)**: La página se desliza de arriba hacia abajo, permitiendo una navegación fluida entre las secciones sin recargar la página.
- **Sección de Perfil**: Información sobre quién soy, con detalles de contacto y una foto de perfil.
- **Sección de Proyectos**: Muestra una galería con algunos de los proyectos en los que he trabajado, con imágenes y descripciones de cada uno.
- **Sección de Habilidades**: Un resumen de mis habilidades técnicas, tanto en desarrollo web como en otras tecnologías.
- **Navbar personalizado**: Un navbar con enrutamientos sencillos para navegar por las secciones principales del portfolio.
- **Diseño Responsive**: La aplicación se adapta a diferentes tamaños de pantalla, garantizando una buena experiencia en dispositivos móviles.

## Tecnologías utilizadas

- **React**: Librería de JavaScript para crear interfaces de usuario.
- **CSS**: Estilos personalizados para el diseño y presentación.
- **React Router**: Para la navegación entre las secciones.
- **Bootstrap**: Para algunos elementos prediseñados como el navbar (aunque personalizado).
- **Devicon**: Para agregar iconos a la interfaz de usuario.
